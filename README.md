# LoveBirdID

LoveBirdID is an automated gender classification system for monomorphic lovebirds using vocalization analysis and Hidden Markov Models (HMMs).

The system uses Mel-Frequency Cepstral Coefficients (MFCCs) extracted from lovebird vocalizations to classify gender in a non-invasive and cost-effective manner. The project was deployed on a Raspberry Pi 4 Model B and evaluated using real-world inference trials.

## Features
- HMM-based gender classification
- MFCC audio feature extraction
- Raspberry Pi deployment
- LCD display prediction output
- Real-time or near-real-time inference
- Non-invasive alternative to DNA testing

## Technologies Used
- Python
- Hidden Markov Models (hmmlearn)
- Librosa
- NumPy
- Raspberry Pi 4
- LCD Display Module
